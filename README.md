# salon-rich-nana-beauty
Website profesional untuk Salon Rich Nana Beauty - layanan kecantikan premium

## Fitur
- Landing page salon yang modern dan elegan
- Desain responsif untuk desktop dan mobile
- Hero section, layanan, galeri, testimoni, kontak, dan CTA booking
- Integrasi tombol WhatsApp booking
- Animasi sederhana serta menu mobile

## Cara menjalankan
Buka file `index.html` di browser, atau jalankan server lokal seperti:

```bash
python -m http.server 8000
```

Lalu akses:

```bash
http://localhost:8000
```
